# 3D N-Body Gravity Simulation

A real-time 3D physics sandbox simulating gravitational interactions between celestial bodies, built from scratch in OCaml.

## Features

- **N-body gravitational physics** with collision detection and body merging
- **Interactive 3D visualization** with orbital trails and explosion effects
- **Multiple scenarios**: Three-body problems, binary stars, solar systems, and more
- **Live parameter editing**: Adjust planet density and radius in real-time
- **Custom physics engine** built entirely with OCaml standard library

## Quick Start
```bash
opam install raylib
dune build
dune exec group90
```

See [INSTALL.md](group90/INSTALL.md) for detailed setup and controls.
